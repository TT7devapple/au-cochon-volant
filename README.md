# Au Cochon Volant

Site vitrine de la rôtisserie Au Cochon Volant, 15 rue Jules-César, 75012 Paris.

Site statique (HTML/CSS/JS), FR/EN, univers papier découpé. Ouvrir `index.html` ou servir le dossier :

```
npx http-server -p 8080
```

- Carte, avis et horaires : `script.js` (ajouter les prix dans `price`).
- Design system : `DESIGN.md`.
